
# Networking Fundamentals

This track focuses on understanding computer networking, communication between systems, network protocols, and practical network configuration.

## Topics Covered

- Networking fundamentals
- OSI and TCP/IP models
- IP addressing and subnetting
- MAC addresses and ARP
- DNS and DHCP
- TCP and UDP
- Ports and network services
- Routing and switching
- Network troubleshooting
- Client-server communication

## Practical Environment

- Ubuntu Server 24.04
- Oracle VirtualBox
- Windows PowerShell
- Linux networking utilities

## Learning Approach

Concept-based learning combined with command-line experiments, network inspection, configuration, and troubleshooting.
