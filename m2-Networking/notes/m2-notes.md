# Month 2 — Networking

## Day 27: How Networks Actually Work

### 1. TCP/IP Model

The TCP/IP model describes how data travels across a network. It has four layers:

| Layer | Purpose | Examples |
|---|---|---|
| Application | Provides network services to applications | HTTP, HTTPS, SSH, DNS |
| Transport | Handles communication between applications | TCP, UDP |
| Internet | Handles IP addressing and routing | IP, ICMP |
| Network Access | Handles communication over the local network | Ethernet, Wi-Fi, MAC |

Connection with Month 1:
- **Application:** Nginx, HTTP, SSH.
- **Transport:** TCP connections used by network services.
- **Internet:** IP addresses and network interfaces.
- **Network Access:** Network adapters and MAC addresses.

### 2. Host OS and Guest OS

Our setup:

- **Host OS:** Windows 11.
- **Virtualization software:** VirtualBox.
- **Guest OS:** Ubuntu Server 24.04.

Windows controls the physical hardware, including the actual Wi-Fi adapter.

VirtualBox creates virtual hardware for Ubuntu, including virtual network adapters.

Ubuntu uses these virtual adapters to communicate with other systems and access the internet.

#### Our VirtualBox Network Adapters

| Ubuntu Interface | Network Type | IP Address | Purpose |
|---|---|---|---|
| `lo` | Loopback | `127.0.0.1` | Ubuntu communicates with itself |
| `enp0s3` | Host-only | `192.168.56.101` | Communication between Windows and Ubuntu |
| `enp0s8` | NAT | `10.0.3.15` | Internet access through VirtualBox NAT |

Both `enp0s3` and `enp0s8` have virtual MAC addresses generated by VirtualBox.

### 3. IP Addresses

An IP address identifies a device or network interface for communication over an IP network.

We encountered these addresses:

| Address | Type | Purpose |
|---|---|---|
| `127.0.0.1` | Loopback | Refers to the local machine |
| `192.168.56.101` | Private | Ubuntu's Host-only interface |
| `10.0.3.15` | Private | Ubuntu's NAT interface |
| `111.119.177.14` | Public-facing | Address reported by an external IP-checking service |

**Important:** Private IP addresses can still access the internet. NAT allows devices using private addresses to communicate with external networks.

The public-facing address reported by an external service may belong to the internet connection's router or provider infrastructure, rather than directly to the VM.

---

### 4. Network Interfaces

A network interface is a connection point through which an operating system communicates over a network.

Our Ubuntu interfaces:

- `lo`: Loopback interface.
- `enp0s3`: Host-only virtual network adapter.
- `enp0s8`: NAT virtual network adapter.

Important interface states:

- `UP`: The interface is administratively enabled.
- `LOWER_UP`: The underlying network link reports that it is operational.

Other terms:

- **MAC address:** Hardware-level address associated with a network interface.
- **Broadcast:** Sends data to all relevant devices on a local network.
- **Multicast:** Sends data to a selected group of devices.
- **Unicast:** Sends data from one device to another.
- **MTU:** Maximum Transmission Unit; the maximum packet size an interface can transmit without fragmentation at that layer.

---

### 5. Routing and Default Gateway

A routing table tells the operating system where to send network traffic.

Our default route:

`default via 10.0.3.2 dev enp0s8`

This means Ubuntu sends traffic for destinations without a more specific route through gateway `10.0.3.2`, using interface `enp0s8`.

Our Host-only route:

`192.168.56.0/24 dev enp0s3`

This means the `192.168.56.0/24` network is directly reachable through `enp0s3`.

### 6. Commands Practiced

#### `pwd`

```bash
pwd
```

Displays the current working directory.

#### `ls -la`

```bash
ls -la
```

Lists files and directories, including hidden files, with detailed information.

#### `ip addr`

```bash
ip addr
```

Displays network interfaces, IP addresses, MAC addresses, and interface information.

Useful variations:

```bash
ip addr show
ip addr show enp0s3
```

- `ip addr show`: Displays interface addresses.
- `ip addr show enp0s3`: Displays address information for a specific interface.

#### `ip link show`

```bash
ip link show
```

Displays network interfaces and their link-layer information, including MAC addresses and interface states.

#### `ip route`

```bash
ip route
```

Displays the routing table, including the default gateway and available network routes.

#### `ping`

```bash
ping 127.0.0.1
```

Tests communication with the local machine through its loopback interface.

```bash
ping 192.168.56.101
```

Tests connectivity to Ubuntu's Host-only IP address.

```bash
ping 10.0.3.15
```

Tests connectivity to Ubuntu's NAT interface.

We also ran this command from Windows PowerShell:

```powershell
ping 192.168.56.101
```

It succeeded, confirming that Windows can communicate with Ubuntu through the Host-only network.

#### `curl`

```bash
curl -4 https://api.ipify.org
```

Makes an HTTP request to an external service and displays the public-facing IPv4 address seen by that service.

- `curl`: Transfers data using a URL.
- `-4`: Uses IPv4.
- `https://api.ipify.org`: External service that reports the request's public-facing IP address.

### 7. Modern `ip` Command vs Legacy `ifconfig`

The `ip` command is the modern Linux networking utility. `ifconfig` belongs to the older `net-tools` package.

| Legacy Command | Modern Equivalent | Purpose |
|---|---|---|
| `ifconfig` | `ip addr` | Display IP addresses |
| `ifconfig -a` | `ip addr show` | Display all interfaces |
| `ifconfig enp0s3` | `ip addr show enp0s3` | Display a specific interface |
| `ifconfig enp0s3 up` | `ip link set enp0s3 up` | Enable an interface |
| `ifconfig enp0s3 down` | `ip link set enp0s3 down` | Disable an interface |
| `route -n` | `ip route` | Display routing information |

We will primarily use the modern `ip` command in this journey.

### 9. Key Lessons

1. Windows is the Host OS, while Ubuntu is running as a Guest OS inside VirtualBox.
2. VirtualBox provides virtual network adapters to Ubuntu.
3. Ubuntu can have multiple network interfaces, each serving a different purpose.
4. Private IP addresses can access the internet through NAT.
5. A MAC address identifies a network interface at the network-access layer.
6. The routing table determines where network traffic should go.
7. `ping` helps test network connectivity.
8. The modern Linux networking utility is `ip`, rather than the legacy `ifconfig`.
