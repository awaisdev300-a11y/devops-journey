
# Linux Fundamentals

This track focuses on learning Linux system administration and command-line fundamentals through practical exercises using Ubuntu Server 24.04.

## Topics Covered

- Linux filesystem and directory structure
- Users, groups, and permissions
- Package management
- Process and service management
- Networking configuration
- Disk and storage management
- Bash scripting and automation
- SSH and remote administration
- Nginx and web server fundamentals
- System troubleshooting and log analysis
- Git-based version control

## Practical Work

- Automated backup script
- Disk usage monitoring
- Service failure investigation
- File permission troubleshooting
- Nginx configuration troubleshooting

## Environment

- Ubuntu Server 24.04
- Oracle VirtualBox
- Windows PowerShell (SSH client)
- Git and GitHub

## Learning Approach

Hands-on Linux administration, command-line practice, troubleshooting, scripting, and documenting practical experience.
